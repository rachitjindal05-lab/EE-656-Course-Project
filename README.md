# EE-656-Course-Project
**Title: Self-Optimal Clustering using Threshold Function**

**Detailed Description:**

Developed as a collaborative research project for the EE656 open elective at IIT Kanpur alongside Kunal, Prakhar, and Abhishek, this project introduces a novel machine learning algorithm called Self-Optimal Clustering (SOC). SOC is designed to overcome a primary limitation of traditional clustering algorithms, such as K-Means or Fuzzy C-Means, which require the user to manually pre-specify the number of clusters. Instead, SOC dynamically and autonomously determines both the optimal number of clusters and the exact locations of the cluster centers.

Building upon the foundations of the Improved Mountain Clustering (IMC) technique, the algorithm operates by projecting data points into a normalized unit hypercube and utilizing a density-based thresholding strategy. The core mathematical innovation lies in how this threshold function is dynamically optimized. Rather than relying on static parameters, SOC iteratively adjusts the clustering threshold using a Lagrange form of interpolation polynomial. By calculating the real roots of this polynomial during each iteration, the model continuously refines its optimizing factor to yield the best possible data groupings.

To ensure the algorithm creates high-quality, meaningful clusters, the model rigorously evaluates its own performance at every step. It prioritizes internal cluster compactness (how closely related data points within a single cluster are) and external separation (how distinct different clusters are from one another). This self-evaluation is driven by standard validation metrics, predominantly the Global Silhouette Index (GSI) and the Separation Index (SI). The algorithm iterates through different parameter states, tracking the GSI, and ultimately selects the configuration that maximizes this index, ensuring the final output represents the mathematically optimal clustering arrangement.

The entire architecture was implemented from scratch in Python using an object-oriented approach. It includes dedicated modules for evaluating mathematical combinations and polynomial roots (DeltaRoots.py), computing cluster validation metrics using scikit-learn (SI.py), and executing the core iterative thresholding logic (soc.py and socimp.py). The project successfully demonstrates the algorithm's practical viability not just on numerical datasets, but also on visual tasks like image segmentation, proving SOC to be a highly reliable, autonomous tool for complex pattern recognition, data mining, and machine learning applications.
